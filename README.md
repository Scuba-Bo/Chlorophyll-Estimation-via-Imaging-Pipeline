# Chlorophyll-Estimation-via-Imaging-Pipeline
Objective: The goal of this image processing pipeline is to be able to measure the chlorophyll concentration (μg/cm2) of coral samples from scientifically color corrected underwater images. Specifically, this pipeline utilizes distance/depth information alongside the values of the red, green, and blue color channels contained in RAW RGB-D images. With this information, we can calculate both the backscatter and wideband attenuation coefficients with a color chart in the image. We then scientifically correct/restore the colors of the underwater image and analyze the RGB values in each pixel to estimate chlorophyll concentration. This could theoretically be a viable, cost efficient, and non-invasive method of chlorophyll measurement that would bypass the destructive practice of taking physical samples for laboratory analysis. 
Current Status: A functioning MATLAB pipeline has been successfully built to process RAW images, but current accuracy is bottlenecked by inconsistent lighting and outdated backscatter/direct signal attenuation estimation methods. The collection of a new dataset with an associated calibration curve and the implementation of modern backscatter/attenuation estimation methods should resolve the current issues. Incorporating accessory pigment considerations may yield novel insights into RGB-D chlorophyll-a estimation methods.
